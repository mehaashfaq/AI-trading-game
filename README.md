# 🎮 AI Market Trader: Higher or Lower Game

An interactive, AI-driven web application built with **Streamlit** and **TensorFlow** where players test their intuition against an LSTM recurrent neural network. The app generates real-time volatile market trends, and players must predict whether the next asset price point will tick **Higher** or **Lower**.

## 🎯 Project Features
* **Deep Learning Trend Engine:** Uses a lightweight TensorFlow LSTM (Long Short-Term Memory) network architecture to capture and project historical structural momentum.
* **Interactive Controls:** Fluid gameplay loops utilizing native Streamlit button triggers and real-time state manipulation.
* **Dynamic UI Visualizations:** Renders high-fidelity, updating sales and pricing velocity line charts using Pandas and Streamlit vector grids.
* **Persistent Scoreboards:** Keeps track of capital accumulation milestones and consecutive winning streaks using securely cached session states.
* **Zero-Overhead Deployment:** Engineered with carefully balanced constraints to prevent out-of-memory container crashes on lightweight cloud platforms.

---

## 🛠️ Tech Stack & Requirements
* **Language:** Python 3.10
* **Framework:** Streamlit (v1.35.0)
* **Deep Learning:** TensorFlow-CPU (v2.12.0)
* **Data Processing:** NumPy (v1.23.5) & Pandas
